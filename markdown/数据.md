### 2.1 知识点 1：Shared Memory 物理微架构
物理位置： 位于 SM 内部的片上高速存储器（On-chip SRAM），与 L1 Data Cache 共享物理 SRAM 资源（通常为 64KB ~ 128KB）。

访问延迟： 仅需 20 ~ 30 个时钟周期（比外部 DRAM 物理显存快 20× 以上）。
#### 1. 32-Bank 映射公式
为了在同一个时钟周期内支持 32 个线程（1 个 Warp）同时并发读写，GPU 硬件将 Shared Memory 在物理上拆分成了 32 个独立演播的存储块（Banks）（Bank 0 到 Bank 31）。

每个 Bank 的宽度为 **4 Bytes (32 bits)**（刚好对应 1 个 float 或 int）。

步骤 3：确定黄金线程数区间 (Golden Rule)
根据 NVIDIA 官方 Tuning Guide 与工程实践：

单 Block 最佳线程数：128 ~ 256 线程（即 4 ~ 8 个 Warps）。
避开 $<64$ 线程（会被 Max Block 槽位卡死）。
避开 $>512$ 线程（会被 Block 挂载数量过少卡死）。
单线程最佳 Tile 工作量：4 ~ 8 个元素/线程。
既能通过循环展开提供足够的 指令级并行 (ILP)，又不会因为单线程用太多寄存器导致寄存器溢出（Register Spilling）到慢速 Local Memory。
